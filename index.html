Funcionalidades

O que foi implementado

✍️

Assinatura digital

PIN de 4 dígitos + hash SHA-256 do conteúdo. Trilha de auditoria completa com responsável, horário e data.

✦

Resumo por IA

Claude API gera resumo automático das ocorrências ao encerrar o turno. Visível no dashboard do gestor.

⚡

Log de ocorrências

Registro com tipo, gravidade (baixa/média/alta) e local. Pendências críticas destacadas automaticamente.

👥

Gestão de equipes

CRUD de membros com convite por link, cargos configuráveis, folgas e trocas de turno com aprovação.

💳

Planos e cobrança

3 planos com Stripe real. Guards de plano no banco via migration — não dá pra burlar por URL.

🔒

Multi-tenant seguro

RLS no Supabase garante isolamento total entre organizações. Nenhuma query vaza dados entre empresas.

Decisões de produto

Por que cada escolha foi feita

"Resumo por IA" em vez de "Chat com IA"

Chat livre com IA em todos os planos = custo recorrente por usuário sem controle. O resumo automático ao encerrar turno é um caso de uso fechado: 1 chamada de LLM, contexto definido pelas ocorrências do turno, resultado útil e previsível. Diferencial real do produto.

Assinatura digital sem plataforma externa

PIN de 4 dígitos com bcrypt + hash SHA-256 do conteúdo + metadata de auditoria (responsável, horário, IP). Zero custo adicional, sem dependência de terceiros, sem necessidade de CNPJ para integrar.

Guards de plano no banco, não no frontend

Limites de equipes, membros e histórico aplicados via migration no Supabase. Não dá para burlar por URL ou manipulação de cliente — a restrição existe na camada de dados.
